# FT-891 manuals

Reference copies of Yaesu's FT-891 documentation, used to build the CAT command tables,
menu ranges, defaults and the menu help text in `ft891prog/menu_help.py`.

The PDFs are Yaesu's copyrighted documents, so they are kept out of Git (see `.gitignore`).
To get them on another machine, download them again from:

| File | Source |
| --- | --- |
| `FT-891_Operating_Manual.pdf` | <https://www.yara.ca/Comms%20Trailer/Comms%20Trailer/FT-891_Operating_Manual.pdf> (FCC/IC application edition) |
| `FT-891_Advance_Manual.pdf` | <https://rigreference.com/storage/manuals/yaesu/FT-891%20Advance%20Manual.pdf--5a6a4b81471ad7.13985438.pdf> |
| `FT-891_CAT_Operation_Reference_Book.pdf` | <https://www.rigreference.com/storage/manuals/yaesu/FT-891%20CAT%20Reference%20Book.pdf--5a6a4c01735456.71645851.pdf> |

The current editions are also available from Yaesu's website (yaesu.com, FT-891 product page,
"Files" tab).

What each one covers:

- **Operating Manual**: installation, front and rear panel, basic operation.
- **Advance Manual**: every feature in detail, including the full menu list (pages 69-73)
  and a description of each menu item (pages 73 onwards).
- **CAT Operation Reference Book**: the computer-control command set (EX menu table,
  MR/MW/MT memory commands, and so on).
